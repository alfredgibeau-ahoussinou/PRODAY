## Le pitch (environ 4 à 5 min)

### 1. Le problème

Convocs WhatsApp, Excel, Mercato Facebook, trajets bricolés, pas d'annuaire santé fiable. Temps perdu, peu de visibilité, recrutement difficile.

### 2. La solution

Une app + [proday75.fr](https://proday75.fr) : carrière, club, santé, événements. IA limitée aux highlights de séance. Annoncer tout de suite covoiturage et santé.

### 3. Covoiturage et Santé, le cœur

| Sujet | Message |
|-------|---------|
| **Covoiturage** | Trajets liés aux matchs et événements, géoloc pendant le trajet |
| **Pôle Santé** | Annuaire + agenda + visio HD Daily. **Santé Pro 19,99 €/mois**, pas gratuite |

### 4. Covoiturage (environ 45 s)

1. **Proposer** : trajet, places, horaires liés à un match, un entraînement ou un lieu
2. **Chercher** : filtres par match, événement, détection
3. **Réserver** : place + messagerie ProDay
4. **Géoloc** : position conducteur partagée pendant le trajet

Cadre : ProDay met en relation, n'est **pas** transporteur.

### 5. Pôle Santé (environ 45 s)

Praticiens **vérifiés** (diplôme avant messagerie complète).
Booking et agenda ; commission **10 %** sur RDV non médicaux.
**Visio HD via Daily**, 15 ou 30 min, **uniquement dans Santé Pro**.
**Santé Pro : 19,99 €/mois.** Pas de plan « visio gratuite ».
7 métiers : Kiné, Ostéo, Médecin, Prépa, Mental, Nutrition, Podologue.

### 6. Autres pôles (environ 30 s)

| Pôle | Idée |
|------|------|
| **Joueur** | Un seul espace. Badges Amateur / Centre / Pro. Genre Homme / Femme. Coach = Staff. |
| **Supporter** | Tribune 100 % gratuite. |
| **Pro Club** | Structures, catégories, recrutement. |
| **Pro Staff** | Coach, Recruteur, Agent (Elite 19,99 puis 29,99 €). |
| **Événements** | Tournois, stages, détections. |
| **Sponsor** | Campagnes ciblées. |

Ne pas s'éterniser. Revenir à covoiturage et santé si ça digresse.

### 7. Tarifs

**Santé Pro** : **19,99 €/mois** (visio 15/30 min) + 10 % sur RDV non médicaux via l'app.
**Agent Elite** : **19,99 €/mois** pour les 20 premiers, puis **29,99 €/mois**.
Joueur Plus 2,99 €. Coach / Recruteur Pro 7,99 €. Club Pro 11,99 €. Organisateur Pro 14,99 €.
Sponsor : Découverte 0 €, Territorial 49 €, National 99 €.
**Parrainage** : 2 filleuls abonnés payants, 1 mois Pro (pas les supporters).

Pas de chiffres d'audience inventés.

### 8. Confiance

Joueurs et supporters : accès rapide. Coach, agent, recruteur, praticien, club : vérification diplôme avant messagerie complète. Mineurs : contrôle parental. Visio Santé = Pro, point.

Expo / React Native, Next.js, Firebase, Daily (visio Santé), IA Mistral (highlights). Vraies données en prod.
