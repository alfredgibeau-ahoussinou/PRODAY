## Le pitch (~4–5 min)

### 1. Le problème

Convocs WhatsApp, Excel, Mercato Facebook, pas d'annuaire staff/santé fiable. Temps perdu, peu de visibilité, recrutement difficile.

### 2. La solution

Une app + [proday75.fr](https://proday75.fr) : carrière, club, communauté, santé, événements. IA honnête — highlights de séance, pas le match frame-by-frame.

### 3. Les 7 pôles (alignés produit / site)

| Pôle | Idée |
|------|------|
| **Joueur** | Un seul espace. Badges Amateur / Centre / Pro. Genre Homme / Femme. |
| **Supporter** | Tribune 100 % gratuite. |
| **Santé** | 7 métiers, annuaire, agenda, **visio dans l'offre Pro** (pas gratuite). |
| **Pro Club** | Structures, catégories, recrutement, vitrine. |
| **Pro Staff** | Coach · Recruteur · Agent · (Organisateur via Événements). |
| **Événements** | Tournois, stages, détections, inscriptions. |
| **Sponsor** | Campagnes ciblées clubs & joueurs. |

**Covoiturage** : différenciateur transversal (Joueur, Club, Événements).

### 4. Tarifs clés (honnêtes)

- **Agent Elite** : **19,99 €/mois** pour les 20 premiers, puis **29,99 €/mois**
- **Santé Pro** : **19,99 €/mois** (visio 15/30 min) + 10 % sur RDV non médicaux via l'app
- Joueur Plus 2,99 € · Coach / Recruteur Pro 7,99 € · Club Pro 11,99 € · Organisateur Pro 14,99 €
- Sponsor : Découverte 0 € · Territorial 49 € · National 99 €
- **Parrainage** : 2 filleuls abonnés payants → 1 mois Pro (pas les supporters)

Pas de métriques d'audience inventées dans ce pitch.

### 5. Confiance

Joueurs / supporters : accès rapide. Coach, agent, recruteur, praticien, club : vérification diplôme avant messagerie complète. Mineurs : contrôle parental.

### 6. Bêta

- **11 août 2026 à 18 h** — TestFlight iOS (lien par email)
- APK Android dès validation
- Liste d'attente : [proday75.fr/beta/inscription](https://proday75.fr/beta/inscription)

### 7. Technique (bref)

Expo / React Native · Next.js · Firebase · IA Mistral (highlights). Vraies données en prod.
