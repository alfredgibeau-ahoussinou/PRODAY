# Vision ProDay — brief produit (août 2026)

Source de vérité produit. Priorité : football amateur et semi-amateur.

## Message

> ProDay accompagne le joueur, le coach et le club avant, pendant et après le match.

> Le quotidien digital du football amateur.

## Utilisateurs (pas de badges de prestige)

Joueur · Coach · Club · Dirigeant / Président · Famille

Interdit en UI : badges « Pro », « Aspirant », « Élite », notes globales, classements artificiels.

## Quatre espaces

1. **Joueur** — progression individuelle, carte joueur, entraînement à domicile, coaching à l’heure  
2. **Coach** — entraînements, IA, tactique, convocations, invitations de match  
3. **Club** — vie sportive, événements, tournois, covoiturage, marketplace, sponsoring, vidéo  
4. **Dirigeant / Président** — tableau de bord, « Ce qui mérite votre attention aujourd’hui »

## Module : Entraînement à domicile & Coach humain

Deux façons complémentaires de progresser :

### À domicile
Bibliothèque d’exercices selon âge, poste, objectifs, matériel. Chaque exercice : vidéo, consignes, répétitions, durée, difficulté, **matériel nécessaire**. Modes : **seul** · **avec partenaire** · **avec famille**.

Parcours joueur CTA visible : **« Je veux m’entraîner »** → À la maison · Avec ma famille · Avec un coach · Réserver une séance.

### Avec un vrai coach (paiement à l’heure)
Pas d’abonnement obligatoire. Flux : Coach → créneau → durée → paiement → séance. Tarif fixé par le coach (fourchette ProDay).

Répartition configurable admin (exemple 30 €) : Coach 25 € · ProDay 3 € · Club 2 €. Coach indépendant = Coach + ProDay seulement.

Après séance : compte rendu (exercices, points +, points à améliorer, devoirs à domicile, objectifs).

> ProDay ne remplace pas le coach. ProDay donne au coach les outils pour accompagner le joueur partout, même en dehors du stade.

## Module : Bourse de recrutement

Principe : **avant de chercher dehors, cherchez dans le club.**

- Coach : besoins d’équipe → matching indicatif sur le vivier interne → proposition de montée / intégration  
- Club : tableau des besoins + correspondances + validation des transferts internes  
- Deux niveaux : **Dans mon club** puis **Entre clubs** (publication ProDay)  
- Score « Correspondance ProDay » = aide, jamais une vérité absolue  

Chaîne : Carte Joueur → Données sportives → Besoins → Matching → Proposition → Validation → Intégration.

## Module : Retard joueur / parent

Sur convocation (match, entraînement, foot / futsal) : **« Je vais être en retard »** en 1–2 clics (&lt; 10 min · ≥ 10 min · je ne sais pas). Notification immédiate au coach (et mention parent si applicable). Feuille de présence : présent · retard · absent · en attente. Arrivée pointée → passage automatique en présent.

## Module : Caméras & Vidéo

> Vous avez une caméra ? Connectez-la à ProDay.

Multi-marques (Veo, XbotGo, Spiideo, Pixellot, Trace, smartphone, import). API quand disponible, sinon import fichier. Jamais d’obligation d’acheter une caméra spécifique. Vidéo reliée au match, à l’équipe et aux joueurs selon les données / autorisations.

## Tarification club

Afficher **Sur devis** (selon adhérents / équipes / options). Bouton **Demander mon devis**. Pas de 39,99 €/mois fixe.

## Pass Joueur

Optionnel **3,99 €/mois** pour fonctions individuelles avancées. Les fonctions essentielles du club restent accessibles sans abonnement joueur. Le coaching humain se paie **à la séance**, pas via un forfait 30 €/mois.

## Règle

Chaque écran résout un problème réel du foot amateur. Pas de fonctionnalité « pour faire joli ».
